# Support

We're here to help! If you are having trouble with PlacementOS, here are the best ways to get support.

## 📖 Getting Help

Before asking for help, please make sure you have:
1. Read the [README.md](README.md) carefully, especially the installation and usage sections.
2. Checked the **FAQ** section below.
3. Searched the [existing issues](https://github.com/vansh070605/PlacementOS/issues) to see if someone else has already reported your problem.

## ❓ Frequently Asked Questions (FAQ)

**Q: I'm getting a MongoDB connection error.**
A: Ensure that your `MONGO_URI` environment variable is correctly set in your `.env` file and that your IP address is whitelisted if using MongoDB Atlas.

**Q: The AI features aren't working.**
A: You must provide a valid `OPENAI_API_KEY` in your backend `.env` file. Also, ensure your OpenAI account has sufficient billing credits.

**Q: How do I update PlacementOS to the latest version?**
A: Run `git pull origin main` in your repository. Then, run `npm install` in both the `backend` and `frontend` directories to install any new dependencies.

## 🐛 Bug Reports

If you've found a bug, please help us fix it by [opening a new issue](https://github.com/vansh070605/PlacementOS/issues/new?template=bug_report.md). 

Please use the **Bug Report** template and provide as much detail as possible, including:
- Steps to reproduce the bug.
- Expected behavior vs. actual behavior.
- Screenshots (if applicable).
- Your operating system and Node.js version.
